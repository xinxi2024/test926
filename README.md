# 上商淘 · 上海商学院校园二手交易平台

> 上海商学院专属校园闲置二手交易 H5 原型 —— 黑客松演示项目

## 📖 项目简介

「上商淘」是面向上海商学院在校学生的二手交易平台，支持商品发布、审核上架、浏览搜索、下单购买、社交发现、即时聊天等完整交易流程。

- **定位**：校园内 C2C 二手交易
- **技术栈**：单文件 HTML + CSS + JavaScript（零依赖，无需构建）
- **适配**：桌面端预览（390×844 手机框）/ 移动端全屏自适应

## 🚀 快速启动

```bash
# 进入项目目录
cd d:\test

# 启动本地服务器（Python 3）
python -m http.server 8000
```

## 🎯 核心功能

### 1. 登录
- 手机号 + 验证码登录（演示验证码：`1234`）
- 第三方登录入口（微信/QQ/校园卡）

### 2. 首页
- 品牌头部 + 通知铃铛
- 搜索框（实时过滤商品）
- 轮播 Banner
- 5 大分类入口
- 排序 Tab（全部/最新/附近/价格）
- 双列商品瀑布流

### 3. 发布商品
- 支持**本地上传图片**（最多 9 张，文件选择器）
- 商品名称（30字限制 + 字数统计）
- 8 大分类选择
- 价格 / 交易选项 / 描述 / 联系方式

### 4. 发现（社交帖子流）
- 帖子卡片：作者头像 + 身份标签 + 时间校区 + 正文 + 多图网格
- 多图布局：1/2/3/4 张自适应
- 点赞 / 评论 / 分享
- 分类筛选 + 排序 + 实时搜索

### 5. 消息
- 会话列表（头像、预览、未读角标、交易中标签）
- 聊天详情页（气泡对话、发送消息、自动回复）

### 6. 我的
- 个人资料卡（信用、ID、简介）
- 数据统计（发布/收藏/订单/浏览）
- 我的服务 / 系统设置 / 退出登录

### 7. 账号设置
- 用户信息卡片（已认证、学号、校区）
- 账号信息（头像/昵称/密码/地址）
- 偏好设置（通知/隐私）
- 快捷开关（交易提醒/系统推送）
- 关于（版本/协议/隐私）

## 🔄 完整交易流程（演示）

```
发布商品 → 平台审核 → 商品上架 → 浏览商品 → 立即购买 → 确认下单 → 交易完成
```

1. **发布**：填写商品信息并上传图片 → 提交
2. **审核**：模拟后端审核，1.5 秒后自动通过
3. **上架**：通过审核的商品出现在首页，带「新上架」标签
4. **购买**：点击商品 → 详情 → 立即购买 → 确认订单 → 下单成功
5. **完成**：商品标记为已售，从列表移除，通知卖家

## 🔌 后端接口预留

前端已在关键流程中预留后端 API 调用注释，便于后续对接：

| 功能 | 接口 | 方法 | 说明 |
|------|------|------|------|
| 发布商品 | `/api/product/publish` | POST | 提交商品信息与图片 |
| 商品列表 | `/api/product/list` | GET | 获取已上架商品 |
| 商品详情 | `/api/product/:id` | GET | 获取商品详情 |
| 审核通过 | `/api/product/approve` | POST | 管理员审核商品 |
| 创建订单 | `/api/order/create` | POST | 买家下单 |
| 订单状态 | `/api/order/:id` | GET | 查询订单状态 |
| 发送消息 | `/api/chat/send` | POST | 发送聊天消息 |
| 登录 | `/api/auth/login` | POST | 手机号验证码登录 |

在代码中搜索 `后端接口预留` 可定位所有预留点。

## 📱 移动端适配

- 使用 `100svh` / `100dvh` 动态视口高度，解决浏览器地址栏挤压问题
- 底部导航栏 `position: fixed` + `safe-area-inset` 安全区适配，始终可见
- 隐藏移动端重复的状态栏
- 触摸优化：`-webkit-tap-highlight-color: transparent`

## 🎨 设计规范

- **主色**：`#1e73e8`（商业蓝）渐变至 `#6ee7f9`（清天蓝）
- **强调色**：`#ff4d4f`（价格/收藏红）
- **圆角**：卡片 14-18px，按钮 12-14px
- **字体**：苹方 / 微软雅黑，标题使用渐变文字效果
- **图标**：全部 SVG 扁平图标
